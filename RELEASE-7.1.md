# Release Vector PNI 7.1 — Physical Realism Refinement

Дата подготовки: 9 ноября 2026. Релиз сохраняет готовую 7.1; новая геометрия и функции на этапе выпуска не добавлялись.

## Проверено перед коммитом

- npm test: 104/104, 0 failures; npm run build:pages: успешно, Vite 6.4.4, base /, pages-dist.
- Production Chrome: 173 draw calls, 334 398 треугольников; 152 геометрии / 10 текстур основной сцены.
- 16 карточек, 15 бортовых геометрических групп, 52 секции и 162 выбираемых листа. Зарядник — внешнее оборудование.
- Уточнения камеры: семь study-поверхностей, +7 360 треугольников только при изучении; 20 существующих шайб уточняются лениво. Материалы, instancing и вложенная разборка сохранены.
- Регрессия: выбор/изоляция/zoom, разборка/сборка, камера, touch, reduced motion; 14 сценариев fallback, включая потерю контекста и retry; все статические изображения/карточки/52 описания доступны.
- Новые контрольные кадры 1440×1000 и 390×844: 3D, fallback, разобранная модель, study камеры. Критических визуальных дефектов в проверенных кадрах не обнаружено; ошибок JavaScript нет.
- Первое сравнение inventory обратилось к выключенному локальному серверу 7.0 на порту 5191 и завершилось connection refused. Для релиза отдельно успешно проверен именно текущий production 7.1 на 5175. Ошибка стенда не засчитана пройденной проверкой.

Подробные отчёты разработки: [итог 7.1](PHYSICAL-REALISM-7.1-FINAL.md) и [52 секции](PHYSICAL-REALISM-52-AUDIT.md). Они описывают этап до релизного коммита. Локальные JSON/скриншоты: qa-artifacts/release71; они не включаются в Git и Pages.

## Ручной запуск публикации

1. Открыть https://github.com/vectorpni/vectorpni.github.io/actions/workflows/pages.yml.
2. Выбрать Publish Vector PNI to GitHub Pages → Run workflow.
3. В Branch выбрать main и нажать зелёную Run workflow.
4. Открыть новый запуск, сверить его commit с релизным SHA, дождаться успешных build и deploy. Если GitHub запросит approval окружения github-pages, подтвердить этот deployment.
5. Открыть https://vectorpni.github.io/, выполнить жёсткое обновление и проверить модель, разборку, study и fallback. Сопоставить JS/CSS с локальным manifest сборки.

Workflow активен по публичному GitHub API и содержит workflow_dispatch; push не запускает этот workflow. В этой задаче dispatch не выполняется. Чтение настройки Pages через API без авторизации вернуло 404: текущий Settings → Pages через API не подтверждён. При необходимости проверить Source = GitHub Actions в интерфейсе репозитория, без смены конфигурации на branch-based deployment.

Инструкция GitHub: https://docs.github.com/en/actions/how-tos/manage-workflow-runs/manually-run-a-workflow.

## Ограничения

Это условная инженерная реконструкция, не подтверждённый заводской цифровой двойник. WebKit и физические телефоны не проверялись. Долговременное отсутствие утечек не гарантируется; ранее зафиксирован ненулевой рост JS heap при неизменных WebGL-счётчиках. Публичная версия 7.1 до ручного запуска не проверяется как опубликованная.
