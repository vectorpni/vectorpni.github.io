## Исправления по результатам осмотра

1. Устранён разрыв между валом двигателя и центральной втулкой. Нижняя часть вала продлена до опоры, исходная верхняя точка сохранена.
2. Под винтами двигателя добавлены четыре монтажные площадки, соединённые с центральной втулкой и внешним ободом. Головки и шайбы получили опору.
3. Стойки рамы продлены до верхних втулок с сохранением нижних точек. Верхние втулки перенесены из `wiring` в `frame`, поэтому больше не улетают вместе с проводкой.
4. Высота нового крепежа рамы согласована с верхней поверхностью втулок; головка не совпадает с плоскостью верхней крышки.
5. В карточках объёмных узлов камера могла входить внутрь корпуса при максимальном zoom, оставляя почти чёрное изображение. Для моторов, батареи, камеры и других объёмных корпусов минимальная дистанция теперь равна 1,05 радиуса bounding sphere. Рама, пропеллеры и тонкие платы сохраняют прежний диапазон. Вращение и zoom работают, оформление карточек не менялось.

Новые площадки входят в существующий статический пакет двигателя. Количество draw calls осталось **202**. Дизайн, цвета, габариты, расположение опор и 16 компонентов сохранены.

## Геометрия и движение

- Проверены 27 уникальных новых BufferGeometry: 35 484 треугольника, без вырожденных/повторных граней, NaN/Infinity и нормалей, направленных против соответствующих граней.
- Модульный тест подтверждает замкнутость и согласованную ориентацию оболочки лопастей. Отдельные проверки подтверждают соединение вала с опорой и стоек с втулками.
- Минимальный вертикальный зазор между общими объёмами рамы и пропеллеров — около 0,081 единицы сцены. Между этими группами пересечений нет.
- Для всех **16 групп и 200 отображаемых дочерних объектов** сравниваются локальные матрицы и мировое перемещение между собранным и разобранным состоянием: локальные матрицы неизменны, смещение каждого объекта равно смещению его группы, сборка возвращает группы к нулю.
- Два последовательных рендера каждого из 16 сравнительных ракурсов побайтно совпали. При осмотре крупных планов нежелательного мерцания не обнаружено.
- Проверка максимального zoom подтверждает, что камера объёмных узлов остаётся вне bounding sphere.

Это не полная CAD-проверка всех внутренних пересечений. Соединения крепежа, втулок и корпуса намеренно имеют небольшой монтажный нахлёст. Проводка сохраняет условное представление разъединённых жгутов при разборке; симуляция кабелей не добавлялась.

## CPU и мобильные разрешения

Chromium 156, Intel UHD / ANGLE D3D11, локальная production-сборка. CPU ×4 — эмуляция Chrome, не физический слабый процессор. Десктоп: 1440×1000, DPR 1, три прогона на версию; ниже медианы.

| Метрика при CPU ×4 | Исходная f1471f5 | Финальная Ultra 4.0 |
|---|---:|---:|
| FPS вращения | 110,1 | 138,2 |
| FPS разборки | 120,6 | 144,6 |
| Draw calls | 186 | 202 |
| Треугольники/кадр | 283 810 | 325 286 |
| JS heap после GC | 10,61 МБ | 11,05 МБ |
| Готовность модели | 1422 мс | 1431 мс |

В прогонах заметен разброс: вращение исходной версии 108–137 FPS, Ultra 136–140 FPS. Эти данные подтверждают работоспособность с CPU throttling, но **не доказывают ускорение Ultra**: архитектура рендеринга не менялась, результат чувствителен к нагрузке ОС, кешу драйвера и пределу около 144 Гц.

Мобильный сценарий: CPU ×4, DPR 2, touch-enabled context, размеры 320×568, 375×812, 390×844, 430×932, 768×1024, 844×390. **52 проверки прошли**: переполнение, панель вне модели, быстрое переключение сборки/ракурсов, сброс, все 16 карточек и отсутствие постоянного RAF в простое. На 390×844 измерены вращение 136,8 FPS и разборка 144,1 FPS, 202 вызова/кадр. Это результат эмуляции на десктопном GPU, не обещание аналогичной скорости телефона.

## Остальные проверки

- Chromium: 101 проверка основного аудита, 23 проверки карточек/восстановления WebGL, 54 сочетания размера/ракурса/сборки, 7 проверок устойчивости. Минимальный запас кадрирования — 11 px.
- Firefox: 101 проверка основного аудита и 23 проверки карточек/восстановления WebGL.
- После потери и восстановления WebGL изображение сцены побайтно совпадает с исходным.
- 12 модульных тестов геометрии, instancing и анимации проходят.
- `npm run build`, `npm run build:pages`, `git diff --check` проходят.
- JS 862,68 КБ / 239,89 КБ gzip; CSS без изменений. Предупреждение Vite о JS >500 КБ до сжатия осталось. Настройки GitHub Pages не менялись.

В финальных сценариях ошибок JavaScript не зарегистрировано. Физические телефоны и Safari/WebKit не проверялись.
