# Vector PNI — Smart 3D Fallback & Component Explorer

Локальная реализация от 04.11.2026. Публикация и отправка в GitHub не выполнялись.
Основа: стабильная 5.2, коммит `7e781eb831a663a70c2eafcc99bc233c7405a20f`.

## Обнаруженные проблемы

- Отказ WebGL оставлял сообщение вместо полноценного просмотра модели.
- Доступ к каталогу был скрыт за иконкой, открывавшей сразу карточку рамы.
- Тяжёлый движок импортировался вместе с интерфейсом, даже без WebGL.
- Перезапуск требовал перезагрузки страницы; ограниченного ожидания первого кадра не было.
- Очистка основной сцены покрывала нормальное завершение, но не все промежуточные ошибки построения и рендеринга.
- При разработке статического каталога найдено и исправлено сохранение состояния раскрытого раздела при переключении на другой компонент: статическое представление теперь получает ключ компонента.

## Что реализовано

Статический снимок именно существующей AF-18 получен из рабочей сцены, без генерации
изображений и изменения конструкции. Основной WebP — **1600 × 1000, 55 212 байт**;
максимальный размер на странице 800 CSS px обеспечивает плотность 2×.
Дополнительно сохранены 15 снимков существующих компонентов по 600 × 480.
Зарядное устройство остаётся внешним оборудованием без вымышленного изображения.

Запасной режим отображается обычными `<img>` и HTML-кнопками. Three.js и WebGL
не используются для его отрисовки. Capability probe выполняет одну попытку
получить WebGL 2; при отсутствии поддержки модуль движка вообще не запрашивается.
При успехе пробный контекст сразу освобождается.

На общем изображении шесть точек видимых компонентов: рама, двигатели,
пропеллеры, аккумулятор, GNSS и камера. Координаты нормализованы относительно
самого изображения, получены проецированием исходных пространственных позиций.
На телефоне остаются три разнесённые точки; все 16 компонентов доступны через
заметную кнопку «Посмотреть компоненты». Скрытые платы не обозначаются точками
поверх случайных внешних деталей, зарядное устройство не помещается на дрон.

Новый список использует **тот же `parts`**, карточки — существующий **`knowledge`**,
статическое изучение 52 разделов — существующий **`engineeringCatalog`**.
Описания, параметры, ссылки, оговорки об условной геометрии не дублировались
в независимом каталоге и не переписывались. Без WebGL вложенные разделы доступны
как текстовая структура; вращение и геометрическая разборка требуют 3D.

Панель списка занимает существующую боковую область на ПК и адаптивную модальную
панель на компактных экранах. Карточки сохранены. Есть видимый фокус, нативные
кнопки Enter/Space, Escape, восстановление фокуса, ограничение Tab и `inert`
для фона мобильного диалога. Области точек — 44 × 44 px. Учитываются safe-area
и reduced motion. Неактуальные 3D-кнопки и жестовые инструкции удаляются из DOM
на время запасного режима.

Финальная проверка перед выпуском уточнила якорь № 04 на реальной лопасти:
нормализованные координаты (0.225, 0.495). Центры всех шести точек сопоставлены
с масками соответствующих компонентов, отрисованными той же сценой и камерой.
Это исправление координат; изображение, дизайн и геометрия не менялись.

## Ошибки и повторный запуск

- Проверка поддержки WebGL 2 до импорта движка.
- Отдельный импорт движка с обработкой отказа необходимых ресурсов.
- **20 секунд** на импорт/первый кадр. После тайм-аута поздний результат не может
  создать сцену; незавершённая сцена размонтируется. Нативный `import()` не имеет
  AbortSignal: сетевой запрос может закончиться позже, но его результат отменён
  на уровне жизненного цикла.
- Ошибки построения, настройки окружения, изменения размера и основного
  рендеринга переводят просмотр в статический режим с очисткой ресурсов.
- При потере контекста изображение появляется сразу. На автоматическое
  восстановление отведено **8 секунд**. Успешное восстановление возвращает 3D;
  ошибка/истечение времени освобождают старую сцену.
- «Повторить запуск 3D» создаёт новую сессию без перезагрузки страницы. Старая
  сессия проходит cleanup до новой. Синхронный предохранитель игнорирует серию
  быстрых нажатий. Повторный отказ оставляет изображение и карточки доступными.
- Очистка идемпотентна и выполняется в обратном порядке владения: наблюдатели,
  обработчики, RAF, OrbitControls, окружение, геометрии/материалы/текстуры,
  рендерер и canvas. Ошибка одного disposer не прерывает остальные.

## Ограничения браузерных проверок

Firefox установлен, но в текущей ограниченной среде завершался `Target crashed`
при создании пустой вкладки, до загрузки проекта. Диагностика содержит
`Failed to launch tab subprocess @SB::LA::SpawnTarget`. Две попытки получить
разрешение на запуск вне ограниченной среды завершились тайм-аутом автоматической
проверки разрешения; такой запуск не состоялся. Успешных тестов Firefox
для этих изменений **нет**.

WebKit запускался, но Playwright не нашёл исполняемый файл `webkit-2370/Playwright.exe`.
Safari, физические iPhone/Android и экранные дикторы не проверялись. Сенсорные
жесты и мобильные размеры проверены эмуляцией Chrome. Проверка счётчиков
ресурсов не является доказательством отсутствия любых возможных утечек при
неограниченном использовании. Синхронную полную блокировку главного потока
браузера таймер JavaScript прервать не способен.
