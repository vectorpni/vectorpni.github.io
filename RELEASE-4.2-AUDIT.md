# Vector PNI 4.2 — final quality and release preparation

29 октября 2026. Кандидат `4.2.0` подготовлен локально. Коммит, push, GitHub Actions deployment и публикация не выполнялись.

## Итог

Проект готов к публикации в пределах выполненных проверок Chromium/Firefox и браузерной мобильной эмуляции. Все 16 компонентов, информация, подсветка, разборка/сборка, управление камерой и фирменный интерфейс сохранены. Основная сцена по-прежнему выполняет **202 draw calls / 325 286 треугольников**.

Перед изменениями сохранён полный снимок рабочей 4.1: `C:/Sites/MyWebsite/vector-af18-4.1-snapshot-2026-10-29`, 105 исходных файлов и `SNAPSHOT.json` с SHA-256. Он собран и используется как неизменяемая контрольная версия. Ранее сохранённая 4.0 тоже используется для сравнения.

**4.0:** более плоское восприятие металла и яркое синее стекло; крупный повторяющийся рисунок карбона заметнее, но менее естественен. **4.1:** лучше различаются металл, окрашенные поверхности, полимер, ткань и стекло; широкие отражения подчёркивают форму. Изображения 15 непустых карточек тоже сравнены. После instancing возможны небольшие различия округления/сглаживания: максимальная средняя разница 0,034 из 255 RGB, не более 0,212% пикселей отличаются более чем на 8 уровней. Геометрия и число треугольников карточек сохранены.

## Исправленные расходы и недочёты

1. **Карточки теряли instancing.** Из основной модели брались исходные Mesh, каждый получал отдельный клон материала. Например, карточка мотора делала 96 вызовов, компьютера — 136. Теперь геометрия и текстуры остаются общими с основной сценой, материалы клонируются через кеш, а мелкие повторения снова объединяются в InstancedMesh. Выбор одного мотора/пропеллера/ESC сохранён.
2. **Повторное обновление статичных матриц.** WebGLRenderer каждый кадр обходил сцену, хотя вращалась камера. После однократного обновления матрицы основной сцены и preview заморожены. Во время разборки/сборки позиции и мировые матрицы дрона обновляются явно; камера продолжает обновляться автоматически.
3. **Владение ресурсами карточки.** Preview освобождает только собственные материалы и instance buffers. Заимствованные текстуры/геометрия основной сцены не удаляются. У instancer появился параметр, запрещающий dispose чужой геометрии при дедупликации; основной просмотр сохраняет прежнее поведение.
4. **Проверка максимального zoom не учитывала InstancedMesh.** У проверочного сценария исправлен расчёт bounds: теперь он учитывает все экземпляры, а не исходную геометрию в начале координат. Повторная проверка подтвердила безопасную дистанцию камеры.
5. Версия `4.2.0` согласована в package.json и package-lock.json. Добавлены `npm test` для всех 18 модульных тестов и `test:preview` для новой регрессии.

## Что произошло с прежними 140 → 131 FPS

Прежнее снижение не удалось воспроизвести как устойчивую причинную связь с материалами. В дополнительной серии **неизменная 4.1** при CPU ×4 дала **113–142 FPS**, а неизменная 4.0 — 110–118 FPS. Это показывает существенное влияние порядка запусков, прогрева и планирования ОС; приписывать все 9 FPS PBR-материалам было бы неверно.

Для финального сравнения применён порядок **4.0 → 4.1 → 4.2 → 4.2 → 4.1 → 4.0**, отдельно при CPU ×1 и ×4. Профайлер оборачивает renderer один раз на кадр, без перехвата каждого из 202 GL draw-вызовов. В 4.1 отдельно измерено около **0,25 мс/кадр при CPU ×4** на повторный обход матриц; в обычном вращении 4.2 этого обхода больше нет. Во время разборки нужный обход остаётся.

### Основная сцена

Chromium 156, Intel UHD / ANGLE D3D11, 1440×1000, DPR 1, localhost production preview. По два прогона каждой версии на режим; медиана двух значений — их среднее. Этого достаточно для проверки кандидата и конкретного устранённого расхода, но не для универсальной гарантии FPS.

Предел среды около 144 Гц маскирует часть запаса производительности; основное доказанное улучшение — снижение расходов и вызовов карточек, а не большой прирост FPS основной сцены.

### Мобильная проверка

CPU ×4, DPR 2, touch-enabled context: 320×568, 375×812, 390×844, 430×932, 768×1024, 844×390. 52 проверки проходят. На 390×844 измерено вращение 143,36 FPS и разборка 143,21 FPS, 202 вызова/кадр.

Оснований дополнительно уменьшать качество в доступных измерениях нет: существующие ограничения DPR 2 для сцены и 1,6 для preview сохранены. Автоматическое снижение качества по предположению о мощности устройства не добавлялось. Это эмуляция CPU/touch на десктопном GPU, а не физический телефон.

## Функциональность и стабильность

- **18 модульных тестов:** прежние анимации/геометрия/PBR/instancing и 3 новых теста кеша preview, геометрических границ, сохранения исходных ресурсов.
- **Chromium: 297 проверок** основного аудита, premium-взаимодействий, WebGL, ресурсов, кадрирования, мобильного CPU ×4 и touch.
- **Firefox: 139 проверок** аудита, карточек, восстановления WebGL и повторного создания preview.
- Все 16 компонентов имеют информацию; внешний зарядник по-прежнему не устанавливается на модель.
- Мировые перемещения 200 отображаемых дочерних объектов согласованы с их 16 группами при разборке и сборке. Геометрия, нормали, индексы и матрицы 1156 исходных Mesh/экземпляров основной сцены совпадают с контрольной версией.
- Проверены быстрые переключения, подсветка, виды камеры, сброс, колесо, pinch, drag, tap, клавиатура и reduced motion.
- 54 сочетания размера/ракурса/сборки проходят; минимальный запас кадрирования 11 px.
- 27 новых геометрических буферов проходят проверку на некорректные нормали, вырожденные и повторные грани. Зазор рама/пропеллеры сохранён.
- Максимальный zoom основной сцены и карточек проверен. Полная CAD-проверка всех внутренних пересечений не выполнялась.
- Основная сцена после WebGL loss/restore даёт побайтно прежнее изображение; preview тоже восстанавливается.
- После 50 созданных контекстов в тесте остаётся один активный контекст и один canvas. Основные счётчики GPU-ресурсов до/после карточек стабильны.
- Минутный стресс-тест: **126 циклов**, все 16 компонентов, переключение видов и разборки, без JavaScript errors; в конце один активный контекст и один canvas.
- В простое постоянного рендеринга нет. В выполненных сценариях утечки WebGL-ресурсов не обнаружены.

## Production и GitHub Pages

`npm test`, `npm run build`, `npm run build:pages`, `git diff --check` проходят. Версии package/lock согласованы, зависимости не менялись. Node 24 соответствует существующему workflow.

Pages artifact содержит ровно 4 файла: HTML, JS, CSS, favicon. Все локальные ссылки на ресурсы проверены HTTP-запросами — 200. Base `/` соответствует размещению `vectorpni.github.io` в корне домена. QA-изображения, тестовые серверы, исходные снимки и отчёты не входят в артефакт.

JS 862 191 байт / 240 340 байт gzip; у 4.1 было 861 662 / 240 221. Рост gzip — **119 байт**. CSS не менялся. Предупреждение Vite о чанке >500 КБ до сжатия остаётся.

Workflow сохранён: ручной `workflow_dispatch`, без автопубликации на push. Ветка main, изменения остаются незакоммиченными. Реальный GitHub Actions запуск этой версии и проверка опубликованной 4.2 намеренно не выполнялись.

## Оставшиеся ограничения

Физические слабые устройства и Safari/WebKit не проверены. Точный VRAM, энергопотребление и работа на каждом драйвере не измерены. Контактная тень остаётся мягкой условной проекцией. На экстремальных планах видны ограничения исходной условной геометрии; полигоны ради косметики не добавлялись.

Новые анимации трансформаций в будущем должны явно обновлять мировые матрицы, как это делает текущая сборка/разборка. Камера по-прежнему обновляется автоматически.

**Заключение:** кандидат 4.2.0 готов к публикации после отдельной команды пользователя; перечисленные ограничения должны сохраняться в release notes.
