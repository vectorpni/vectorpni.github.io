# AEROFIBER — 3D-сцена дрона

Запуск: start.cmd или npm run dev -- --port 5174
Адрес: http://127.0.0.1:5174
Сборка: npm run build

Один экран с моделью в центре. Перетаскивание вращает модель; колесо изменяет масштаб. Нажатие на видимую деталь открывает модальное окно характеристик. Закрытие: крестик, Escape или фон. «Разобрать» открывает внутренние компоненты.

Модель создана процедурно по референсу: карбон, пластины с прорезями, провода, моторы, воздушные винты, платы, BEC, аккумулятор, GNSS, антенны, охлаждение, камера, шасси и крепёж. Геометрия приблизительная, не CAD-копия. Данные характеристик — из приложенной пользователем таблицы; отсутствующие значения отмечены.

Проверка из родительской папки при работающем сервере:
playwright-cli -s=drone open http://127.0.0.1:5174 --browser=firefox
playwright-cli -s=drone run-code --filename=drone-lab/qa-v2.js
